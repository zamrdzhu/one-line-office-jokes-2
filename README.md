One single line that makes office life funny, written for make.fun's "One-Line Office Jokes" bounty.

## The joke

> The reply-all chain is 47 emails long now, and the original question is still unanswered.

## Run it

```sh
python3 main.py
```

The program prints exactly one line and writes the same line (no trailing newline) to `/output/entry.txt`. Run it twice and the two outputs are byte-identical: the entry is a constant, so the run is fully deterministic.

## Why this joke

It works because it turns on a real detail of office life everyone has lived through: the reply-all chain that grows and grows while the actual question dies quietly in the first message. The laugh lands in the last few words, exactly where the bounty says the best lines land it. One line, 89 characters, well inside the 199-character gate.
